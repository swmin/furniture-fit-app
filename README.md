# 🛋️ 가구들어갈까 (`furniturefit`)

> **"이 가구, 우리 집에 들어갈까? 문은 다 열릴까?"**  
> 도면 사진 한 장(또는 방 가로×세로 치수)으로 가구·가전 배치를 **mm 단위**로 미리 시뮬레이션해 보는 2D 평면 배치 앱입니다.

---

## ✨ 주요 지원 기능

### 1. 집 & 도면 등록
- **도면 사진으로 만들기**: 부동산 앱 캡처 화면, 분양 카탈로그 평면도, 직접 촬영한 도면 사진을 불러와 배경으로 사용합니다.
- **2점 기준선 축척 보정 (Calibration)**: 도면에서 실제 길이를 알고 있는 벽이나 치수선의 양 끝 2점을 찍고 실제 길이(`mm`)를 입력하면 픽셀당 실제 길이(`mm/px`)가 자동 계산됩니다.
  - 정밀 조정을 위한 **원형 확대 돋보기(Loupe)** 및 **수평·수직 자동 스냅** 지원
  - 언제든 상단 자(`📏`) 아이콘으로 축척 재보정 가능
- **빈 방 직접 만들기**: 도면 이미지가 없어도 방의 가로×세로(`mm`)만 입력하면 10cm/50cm 모눈 그리드와 치수선이 있는 방을 즉시 생성합니다.

### 2. 한국형 가구 · 가전 라이브러리 & 내 가구
- **기본 라이브러리 (35종 프리셋)**: 국내 표준 규격의 침대(싱글~라지킹), 장롱(1자·2자·4자), 서랍장, 책상, 소파, 식탁, 주방가전(일반/키친핏 4도어 냉장고, 김치냉장고), 생활가전(세탁기, 건조기, 워시타워, 스탠드 에어컨, 로봇청소기 등)을 카테고리별·검색으로 바로 추가할 수 있습니다.
- **직접 입력 & 내 가구 저장**: 줄자로 잰 내 가구의 `이름`, `가로(W) × 세로(D) × 높이(H) mm`, `색상`, `문 열림 방식(여닫이 1짝 / 양문형 2짝 / 서랍)` 및 `문 열림 반경(mm)`을 직접 입력하고 **내 가구**에 저장해 다른 배치안에서도 재사용할 수 있습니다.

### 3. 정밀 배치 편집 & 공간 간섭 체크
- **드래그 이동 & 자동 자석 스냅**: 가구를 드래그하면 방 벽면이나 이웃 가구 모서리에 자석처럼 깔끔하게 맞춰집니다.
- **90° 회전 & 5° 자유 회전**: 하단 `90° 회전` 버튼으로 빠르게 돌리거나, 가구 위 회전 핸들을 드래그해 `5°` 단위로 대각선 배치를 할 수 있습니다.
- **4방향 실시간 간격(mm) 표시**: 가구를 선택하면 상·하·좌·우 가장 가까운 벽 또는 다른 가구까지의 남은 거리를 실시간으로 보여줍니다.
  - 통로 폭이 **600mm 미만**으로 좁아지면 주황색 경고 라벨로 알려줍니다.
- **문·서랍 열림 반경 시뮬레이션**: 장롱, 냉장고, 서랍장 등의 문이 열리는 부채꼴/서랍 궤적을 표시하고, 문이 열리는 공간에 다른 가구나 벽이 걸리면 **문 열림 방해 경고**를 띄웁니다.
- **가구 겹침 & 방 이탈 경고**: 회전된 가구를 포함해 가구끼리 1mm라도 겹치거나 방 밖으로 벗어나면 빨간 테두리와 상단 경고 배너로 즉시 알려줍니다.

### 4. 다중 배치안 비교 · 실행취소 · 이미지 공유
- **배치안 무제한 생성 & 복제**: 한 집에서 `배치안 1`, `배치안 2`, `침대 창가안` 등 여러 배치안을 무제한으로 만들고, 기존 배치안을 통째로 복제해 비교할 수 있습니다.
- **실행취소 / 다시실행 (Undo / Redo)**: 배치안별로 최대 40단계까지 이동·회전·추가·삭제 이력을 되돌리거나 다시 실행할 수 있습니다.
- **배치도 PNG 이미지 내보내기 & 공유**: 도면, 가구 치수 라벨, 문 열림 반경, 축척 바가 포함된 깔끔한 PNG 이미지로 렌더링하여 카카오톡·메시지·갤러리 등으로 바로 공유할 수 있습니다.

## 📖 앱 사용 방법 (Step-by-Step)

### Step 1. 집 만들기
1. 홈 화면 우측 하단의 **`+ 새 집 만들기`** 버튼을 누릅니다.
2. **도면 사진이 있다면**: `갤러리에서 도면 선택` 또는 `카메라로 도면 촬영`을 선택합니다.
   - 이어서 열리는 **축척 맞추기** 화면에서 도면 속 치수선(예: 안방 가로 `3,600`)의 양 끝점을 돋보기로 정확히 맞추고 실제 길이(`3600` mm)를 입력한 뒤 **`보정 완료`**를 누릅니다.
3. **도면 사진이 없다면**: `빈 방 직접 만들기`를 선택하고 방 이름과 가로·세로 길이(예: `3600` × `4200` mm)를 입력해 방을 생성합니다.

### Step 2. 가구 추가 및 배치하기
1. 편집 화면 하단의 **`+ 가구 추가`** 버튼을 누릅니다.
2. **라이브러리** 탭에서 원하는 가구/가전을 검색해 선택하거나, **직접 입력** 탭에서 가로·세로(mm)와 문 열림 반경을 입력해 추가합니다.
3. 캔버스에 놓인 가구를 터치해 드래그하면 원하는 위치로 이동하며, 선택된 가구 주변에 **벽/이웃 가구와의 간격(mm)**이 자동으로 표시됩니다.
4. 가구를 선택한 상태에서 하단 툴바를 이용해 **`90° 회전`**, **`크기 수정`**, **`복제`**, **`삭제`**를 수행하거나, 가구 위쪽의 초록색 회전 핸들을 끌어 원하는 각도로 회전합니다.
5. 상단 앱바의 **문 아이콘(`🚪`)**을 누르면 배치된 모든 가구의 문·서랍 열림 반경을 한눈에 켜거나 끌 수 있습니다.

### Step 3. 여러 배치안 비교 및 이미지 공유하기
1. 상단 칩 바에서 **`+ 배치안`**을 눌러 새 배치안을 만들거나, 현재 선택된 배치안 칩을 다시 탭(또는 길게 터치)해 **`이 배치안 복제`** / **`이름 변경`** / **`삭제`**를 할 수 있습니다.
2. 배치가 끝나면 우측 상단의 **공유 아이콘(`📤`)**을 눌러 배치도 PNG 이미지를 생성하고 가족, 이사업체, 동거인에게 바로 공유하세요.

| :--- | :---: | :---: |
| 도면 축척 보정 / 빈 방 만들기 | ✅ | ✅ |
| 가구·가전 35종 라이브러리 & 직접 입력 | ✅ | ✅ |
| 실시간 간격 측정 · 문 열림 반경 · 겹침 경고 | ✅ | ✅ |

## 🛠️ 개발 환경 및 실행 방법

### 요구 사항
- **Flutter SDK**: `^3.47.0` (Dart `^3.13.7`)
- **Android SDK**: API 35 이상 권장

### 주요 기술 스택
- **상태 관리 & 라우팅**: `flutter_riverpod`, `go_router`
- **로컬 데이터베이스**: `drift` + `drift_flutter` (SQLite)
- **2D 캔버스 & 기하 연산**: `CustomPainter`, 분리축 정리(SAT) 기반 회전 사각형 충돌·간격·문 반경 엔진 (`lib/domain/geometry/placement.dart`)
- **이미지 · 공유 · 수익화**: `image_picker`, `share_plus`, `google_mobile_ads`, `in_app_purchase`, `shared_preferences`

### 로컬 실행 및 테스트
```bash
# 패키지 설치
flutter pub get

# 정적 분석 및 단위 테스트 (23개 테스트)
flutter analyze
flutter test

# 연결된 Android 기기 또는 에뮬레이터에서 실행
flutter run

# 디버그 APK 빌드
flutter build apk --debug
```
